# Кодировки

Файлы в этой папке записаны в разных кодировках. Часть из них не UTF-8,
поэтому проверка кодировок и чтение должны показать замечания.

- `cp1251.md` — Windows-1251;
- `koi8-r.txt` — KOI8-R;
- `cp866.txt` — CP866;
- `latin1.txt` — Latin-1/CP1252;
- `utf-16le.txt`, `utf-16be.txt` — UTF-16 с BOM;
- `invalid_utf8.md` — битые байты;
- `utf8_bom.md` — UTF-8 с BOM;
- `shift_jis.txt` — японский Shift-JIS.

Это не ошибки демо-хранилища: так и задумано.
