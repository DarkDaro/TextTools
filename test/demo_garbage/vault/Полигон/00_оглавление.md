## Что проверять

| Инструмент | Что искать |
| --- | --- |
| find_cjk | китайский, японский, корейский, мойбейк |
| clean_text | мусор, управляющие символы, CJK |
| emoji | эмодзи, флаги, ZWJ, текстовые смайлы |
| whitespace | NBSP, табы, zero-width, CRLF/CR |
| typography | кавычки, тире, многоточия |
| encoding | cp1251, KOI8-R, cp866, UTF-16, Latin-1 |
| refile | даты в тексте и в коде |
| md_replace | старые имена и замена слова |
| char_search | реестр имён и падежи |
| merge | точные и почти-дубли |
| orphans/broken | сироты, битые ссылки, вложения |
