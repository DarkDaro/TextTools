# AGENTS.md — правила работы с репозиторием TextTools

## Правило №1: коммит после каждого шага

Один шаг работы = быстрый тест = один коммит. Код и документация едут
в одном коммите, без чанков и «докоммичу потом».

Незакоммиченное — потерянное: песочница может откатиться в любой момент,
и всё, что не попало в коммит, пропадает безвозвратно. Коммит — единственная
защита работы.

## Быстрый тест перед коммитом

- CLI-логика инструментов: точечный `python test_<модуль>.py`.
- GUI: точечный тест нужной вкладки (например `python test_settings.py`)
  под Xvfb: `DISPLAY=:77 python test_settings.py` (Xvfb поднять заранее).
- Тест красный — сначала фикс, потом коммит. Не коммитить красное.

## Гигиена

- `git status` чист на границе любого шага; не заканчивать шаг с грязным деревом.
- Токен GitHub (PAT) — только для `git push`; никогда не попадает
  в коммиты, документацию и вывод команд.
