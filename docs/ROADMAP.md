# Дорожная карта

Заведена 27.11.2026, когда выяснилось, что «что дальше» жило в
разрозненных хвостах, а не в одном месте. Правила простые: пункт
попадает сюда, только если он реально будет делаться; сделанное —
уезжает в CHANGELOG; «когда-нибудь» здесь не живёт — если захочется,
заведётся само.

## Точка сейчас (27.11.2026)

  `update`); pytest 354 + 1 живой под дисплей; meta-check, смоук,
  doctor — зелёные.
* «Помодоро» доведена до конца замысла: задача цикла, отвлечения

  закрыты.
* Техдолг TD-01…TD-09 закрыт; TD-06 (запускалки только под Windows) —
  не долг, а граница.

## Следующие заходы (по порядку, не одновременно)

1. **Перевод вкладок на английский** (`ui_lang`, план —
   docs/LOC_PLAN.md): пилот готов, осталось семь вкладок. Темп —
   вкладка = коммит = её GUI-тест, без марафонов.
2. **CLI-режим «Помодоро»** — движок чистый и без tkinter, задел
   лежит с 18.11. Делать, когда таймер в терминале станет нужен
   по-настоящему, а не «для симметрии».
3. **Сохранение сессий «Помодоро» между запусками** — пока итог
   живёт один запуск и это честно. Если понадобится — JSON-ключ в
   gui_config.json рядом с дневной статистикой. SQL не будет:
   разговор с таблицами у меня не задался.
4. **Статистика письма глубже** — если дневник `stats --history`
   перестанет отвечать на вопросы, который он уже отвечает.

## Не будет сделано (решено, не обсуждается)

* SQL/SQLite в пользовательских данных — хранить нечего, читать
  негоже, автор в этом не признается.
* Сеть в таймере, Telegram-бот, командный таймер — офлайн-инструмент
  для одного писателя, которому хватит окна.
* Автоисправление содержимого рукописи машиной — правило «решение
  по контексту за автором» не трогается.
* Скриншоты без явного шага приёмки — насмотрелись.
