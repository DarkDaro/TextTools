# Скриншоты TextTools

Все 8 разделов окна в обеих темах, окно 1280x800. Сняты в тестовой
песочнице (Xvfb) с подменой шрифта на DejaVu Sans — на Windows
интерфейс рисуется шрифтом Segoe UI, пропорции те же.
