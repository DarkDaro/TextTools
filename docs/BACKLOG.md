## Сознательно не делается (зафиксировано)

- GUI-автотесты: customtkinter в песочнице недоступен, решено 05.11 —
  GUI проверяется дымовым прогоном вручную. (Позже 05.11 дисплей в
  песочнице появился и GUI-тесты вернулись — см. CHANGELOG за этот
  день; пункт остаётся как историческое решение.)
- Автоисправление soft-вхождений АНТИРЕШИМОСТИ: правило — решение по
  контексту за автором, машина не трогает.
- Полный паритет с форматированием Word (пересборка стилей, полей):
  вне рамок — инструмент текстовый, не вёрстка.
- В `export-docx`: Word-таблицы и нумерация стилем List Number
  (продолжает счёт по документу) — нумерованные списки пишутся
  текстом номера; ё/е и типографика — только ДО экспорта.
- В `echo`: машинная «умность» (лемматизация, синонимы) — эхо ловит
  точные конструкции; порог шума отдаётся автору (--n, --min-files,
  --top, --registry).
