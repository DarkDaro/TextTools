# Состояние проекта

Снимок «где мы сейчас». Обновляется вручную в конце рабочей сессии;
история по дням живёт в CHANGELOG.md, этот файл — про текущее.
Заведён 18.11.2026: аудиты и правки делались, но нигде не сходилось
в одно место — что уже работает, что проверено, что осталось. Теперь
сходится здесь.

## Снимок: 21.11.2026, версия 1.9.0

* окно на 8 вкладок: Писателям, Имена персонажей, Хранилище, Чистка,
  Замены, Помодоро, Настройки, Журнал;
* CLI: 32 подкоманды и 33 имени (алиас pathos = antiresolve);
  у шести языковых команд — флаг --lang ru|en; у четырёх vault-команд —
  предохранители --max-mb/--max-min; новая команда update — обновление
  с GitHub (проверка по умолчанию, --apply — применить);
* ядро pytest: 323 теста, зелёное; настройки 149/0, дым и кнопочная
  геометрия — зелёные;
* самообновление: tools/updater.py — git fetch/merge --ff-only с
  запасным zip-путём; кнопки «Проверить обновления» / «Обновить
  сейчас» / «Проверка целостности» на «Настройках» (раздел
  «Обновление и целостность»); update.bat v5 — шаг doctor после
  обновления; сеть работает только по явной команде;
* предохранители (core/fuse.py): лимит размера файла (по умолчанию
  64 МБ), бюджет времени (20 минут), стоп-файл «Стоп»; scan_vault
  под ними всегда; поля «Предохранитель: файл, МБ» и «время, мин»
  на «Настройках» (fuse.max_mb / fuse.max_min);
* двуязычие (docs/LOC_PLAN.md): язык текстов text_lang и язык
  интерфейса ui_lang; core/i18n.py и tr() — пилот подмены строк,
  перевод остальных вкладок — следующие заходы;
* всё запушено на origin/main, рабочее дерево чистое;
* проверка доков (скрипт живёт вне репозитория, в песочнице
  разработчика) — зелёная: версии, вкладки, счётчики, локальные
  ссылки, структура TECH_DEBT.

Разработка идёт в Linux-песочнице под Xvfb по правилам AGENTS.md
(один шаг = быстрый тест = один коммит). Запускатели и патник —
только под Windows, это осознанная граница (TD-06).
