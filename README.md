# TextTools

Настольный набор инструментов для анализа и массовой обработки текстовых
заметок (markdown-хранилища Obsidian, txt, docx): реестр персонажей
с морфологией, проверка консистентности имён, матрица упоминаний,
поиск «осиротевших» заметок, битых ссылок и дубликатов, валидатор
метафайлов Obsidian, поиск иероглифов и порчи кодировки, чистка штампов,
пробелов и эмодзи, массовые замены, обслуживание кодировок и бэкапов.

Версия 1.0.0. Windows, Python 3.10+. Работает локально: тексты никуда
не отправляются. Всё, что меняет файлы, сначала показывает отчёт;
реальная запись включается отдельно и сопровождается бэкапом.

**Полное руководство пользователя (для авторов и писателей) —
[MANUAL.md](MANUAL.md): готовые сценарии, справочник по всем кнопкам и
полям, формат реестра, частые вопросы.**

**Пошаговый путеводитель по окну программы для тех, кто не
программирует: [GUI_GUIDE.md](GUI_GUIDE.md).**

Вехи обслуживания и исправления: [CHANGELOG.md](CHANGELOG.md).

Два режима запуска:

* **CLI** — `textools.py` (единая точка входа, argparse-подкоманды)
* **GUI** — `gui_ctk.pyw` на CustomTkinter (6 вкладок, включая журнал),
  запуск через `textools_gui.bat` или `python gui_ctk.pyw`

## Установка

```
pip install -r requirements.txt
```

`textools` можно запускать прямо из папки проекта. Глобально в общий
Python его ставить не нужно: пакет содержит общие имена `core`, `tools`,
`wrappers`, и они могут перекрыть модули других проектов.

Если всё же нужна команда `textools` в системе, ставьте пакет в
отдельное окружение, а не в общий Python:

```
py -3.14 -m venv .venv
.venv\Scripts\activate
pip install .
textools --version
```

Зависимости: `pyyaml`, `python-docx`, `customtkinter`, `pymorphy3`
(падежные формы имён), `charset-normalizer` (определение кодировок),
`tkinterdnd2` (перетаскивание файлов в поля — при её отсутствии
программа работает, но без drag&drop). Пакетные метаданные —
в `pyproject.toml`.

## Возможности

* **Персонажи**: registry-builder находит имена-кандидаты; реестр YAML
  (`имя/формы/старое/старое_опасное/опечатки`); consistency проверяет
  тексты по реестру, находя старые имена и опечатки в любых падежах
  (pymorphy3, ё/е эквивалентны); forms дописывает недостающие падежи
  в реестр; matrix строит таблицу «персонаж × файл».
* **Хранилище**: orphan-finder, broken-links, merge-finder, integrity
  (целостность заметок), поиск и интерактивная чистка штампов
  (витрина с выбором вхождений).
* **Валидатор Obsidian**: `obsidian-check` проверяет то, что Obsidian
  молча ломает — frontmatter, заголовки, таблицы, теги, code fence,
  ссылки, посимвольно разбитый текст. Severity ERROR/WARN/INFO,
  `--fix` правит однозначное с бэкапом `.bak`.
* **Замены**: массовая замена в .md/.txt/.docx (в docx — включая фразы,
  разорванные между run'ами, с сохранением форматирования), диагностика
  символов и кодировок, точечная замена слова, regex-замена по папке.
* **Чистка**: эмодзи и смайлы, мусор/CJK по белому списку, пробелы и
  пустые строки вне код-блоков, приведение текстов к UTF-8 (koi8-r,
  cp1251 распознаются автоматически), типографика: «ёлочки» (включая
  „лапки“ и вложенные цитаты), тире, многоточия, диалоговое тире,
  опционально неразрывные пробелы (`--nbsp`).
* **Стилистика**: отчёт о повторах слов в пределах окна (тавтологии) и
  слишком длинных предложениях; статистика со словами-паразитами
  (список настраивается в `tools/parasites.yaml`) и CSV-дневником
  объёма (`stats --csv` → `reports/stats_log.csv`).
* **Ё/Е-аудит**: спорные места с ё — имена из реестра (Семён/Семен),
  словарные пары и омографы (все/всё, небо/нёбо). Витрина с контекстом,
  замена только по выбранным вхождениям (`tools/yo_audit.py`).
* **Обслуживание**: обзор и восстановление из бэкапов (`.bak` и
  `md_replace_backups/`), архивация старых бэкапов в `archive/backups`
  (перенос, ничего не удаляется), история операций в `logs/history.log`,
  мягкая остановка долгих операций (кнопка «Стоп» даёт программе
  корректно завершить текущий файл).

## CLI

```
python textools.py registry-builder --input <папка> [--registry <yaml>] [--min-count N]
python textools.py consistency      --input <папка> --registry <yaml>
python textools.py forms            --registry <yaml> [--fill]
python textools.py matrix           --input <папка> --registry <yaml>
python textools.py merge-registry   --candidates <yaml> --registry <yaml> [--add]
python textools.py utf8             --input <папка> [--fix]
python textools.py orphan-finder    --input <папка>
python textools.py broken-links     --input <папка>
python textools.py merge-finder     --input <папка>
python textools.py integrity         --input <папка>
python textools.py obsidian-check    --input <папка> [--fix] [--no-bak] [--exit-zero] [--out report.md]
python textools.py cjk              --input <папка> [--ext .md,.txt] [--json report.json]
python textools.py restore          --input <папка> [--restore] [--file <имя>]
python textools.py archive-backups  --input <папка> [--days 30] [--move]
python textools.py moc              --input <vault> --registry <yaml> --out-dir <папка> [--apply]
python textools.py stats            --input <папка> [--out report.md] [--csv]
python textools.py typography       --input <папка> [--fix] [--nbsp]
python textools.py style-report     --input <папка> [--registry <yaml>] [--window 5] [--long 25]
```

Общие опции: `--out <файл>` (отчёт), `--limit N`, `--verbose`.
Долгие операции печатают прогресс `PROGRESS:N/M`.

## GUI

Подробная человеческая инструкция по окну, всем кнопкам и сценариям
работы: [GUI_GUIDE.md](GUI_GUIDE.md).

Вкладки:

* **Имена персонажей** — registry-builder, consistency, матрица
  упоминаний, падежные формы (pymorphy3), добавление кандидатов в
  реестр, MOC-заметки персонажей для Obsidian
* **Хранилище** — orphan-finder, broken-links, merge-finder, проверка
  целостности заметок (integrity), валидатор Obsidian
  (obsidian-check), поиск иероглифов и мойбейка (find_cjk), поиск
  штампов, чистка штампов (в том числе интерактивно, с витриной),
  статистика текста (с CSV-дневником объёма), стилистический отчёт
  (повторы слов рядом, длинные предложения)
* **Чистка** — эмодзи, мусор/CJK, пробелы, кодировки (UTF-8),
  типографика («ёлочки», тире, многоточия, неразрывные пробелы)
* **Замены** — md_replace (4 режима), char_search, точечная замена
  слова, refile
* **Настройки** — пути к внешним скриптам, тема, проверки заметок
  (расширения для иероглифов, `.bak` валидатора), обслуживание бэкапов,
  общие параметры, сведения о программе и проверка зависимостей
* **Журнал** — вывод инструментов: поиск с подсветкой, очистка,
  копирование, сохранение отчёта, масштаб шрифта

У каждого поля и кнопки есть всплывающая подсказка. Цвет кнопки
показывает смысл: зелёная — проверка или отчёт без записи, акцентная —
обычный запуск, красная — реальная запись (появляется сразу при
включении «Применить» или снятии dry-run). Долгие операции
показывают прогресс-бар в статусной строке над вкладками: реальный
счётчик «12/45», либо пульс, пока инструмент не сообщает процент.
На время операции кнопки инструментов блокируются (второй запуск
параллельно невозможен), справа снизу появляются всплывающие тосты с
системным звуком ошибки/завершения, статус показывает имя инструмента
и время работы. Любой путь можно вставить правым кликом («Вставить из
буфера», кавычки снимаются), история поля хранит 10 последних путей.
Горячие клавиши: Ctrl+1…6 — вкладки, Ctrl+F — поиск в журнале,
Ctrl+S — сохранить настройки. Размер окна и последняя вкладка
восстанавливаются при запуске.

**Безопасность:** все операции с записью идут в dry-run; реальная запись
только через чекбокс «Применить изменения». Перед записью создаются
бэкапы (`.bak` рядом или `md_replace_backups/<дата-время>/`;
восстановление — вкладка «Настройки»).

Конфиг GUI — `gui_config.json` (пути, тема, состояния чекбоксов).

## Структура

* `core/` — парсер текста, реестр имён, сканер vault, docx (включая
  кросс-run замену), морфология (pymorphy3), кодировки
* `tools/` — движки команд (registry_builder, consistency, orphan_finder,
  broken_links, merge_finder, integrity_check, obsidian_check, phrase_check,
  whitespace_clean, utf8_convert, morph_forms, character_matrix,
  registry_merge, backup_restore, backup_archive, moc_builder, text_stats,
  typography, style_report) + словари `phrases*.yaml`, `parasites.yaml`
* `find_cjk.py` — поиск иероглифов, мойбейка и порчи кодировки
  (CLI `cjk`, карточка на вкладке «Хранилище»)
* `wrappers/` — сборка командных строк для **внешних** скриптов
  (emoji-cleaner, md-replace, char_search, refile, clean_text_files);
  сами скрипты лежат вне репозитория, пути к ним задаются в настройках
  GUI (вкладка «Настройки» → «Пути к внешним скриптам»)
* `gui_ctk.pyw`, `tabs_*.py`, `widgets_ctk.py`, `review_dialog.py` — GUI
* `GUI_GUIDE.md` — пошаговая инструкция по окну программы
* `pyproject.toml` — метаданные проекта (версия, описание, зависимости,
  точка входа `textools`)
* `gui_config.example.json` — минимальный пример конфига; рабочий
  `gui_config.json` создаётся программой и в git не входит
* `reports/` — выходные отчёты (в git не входит)

## Тесты

Тесты лежат в `archive/` и `test/` (обе папки не входят в git):

```
cd archive
python test_engines.py   # проверки движков и CLI

cd ..
python test_gui.py                    # проверки GUI (открывает окно)
python test/test_obsidian_check.py    # obsidian-check: находки и --fix
```

Каждый набор сам пересоздаёт тестовый корпус `archive/corpus/`, порядок
запуска не важен. Подробности — `archive/README.md`.
