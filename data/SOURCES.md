# Источники словарей

## data/resolve_db.yaml — АНТИРЕШИМОСТЬ
Авторские правила по памятке романа «История Даро. Проект Восход»:
запрещённая лексика (§1), лозунги, превозмогание, назидательные выводы.
Пополняется вручную по мере работы над текстом.

## data/pathos_db.yaml — АНТИПАФОС
Авторский стартовый набор: эпитеты героизма, пафосные конструкции,
обобщения-клише. Пополняется вручную.

Планируемый внешний источник пополнения — проект
[ru-text](https://github.com/talkstream/ru-text) (лицензия MIT, справочники
в Markdown лежат в самом репозитории, без сетевых запросов): списки
стоп-слов и пары «плохо → хорошо» конвертируются в YAML один раз и
кладутся сюда; после конвертации интернет не нужен.

## Морфология
Правила с полем `word:` разворачиваются в падежные формы через
[pymorphy3](https://github.com/no-platypus/pymorphy3) (лицензия MIT) со
словарями OpenCorpora — ставится из requirements.txt один раз, дальше
работает офлайн. Без pymorphy3 правило `word:` ищет точное написание —
утилита остаётся работоспособной.
